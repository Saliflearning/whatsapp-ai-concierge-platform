# Shared AI Collaboration Rules

This repository is a fresh-history, privacy-safe public showcase. It is not the
client production repository and must never receive client code, configuration,
exports, conversations, contact details, credentials, or screenshots.

Before work:

1. Read `.specify/memory/constitution.md` and the active feature artifacts.
2. Inspect Git status and `docs/assistant-handoffs.md`.
3. Run Graphify in code-only mode when semantic extraction is unavailable.
4. Use Spec Kit gates for substantial changes.

Before ending:

1. Run tests, lint/type/build, dependency audit, and redacted privacy/secret scans.
2. Append a concise entry to `docs/assistant-handoffs.md` with branch, commit,
   verification, risks, and exact next step.
3. Propagate any repository rename, visibility, URL, or location change to the
   private shared portfolio coordination hub.

All demo identities and data MUST be visibly synthetic. Never claim this public
repository is the private production deployment.
